# Qt Projects Collection

A collection of Qt (C++ & Python) desktop applications and school exercises.

## Projects Included:
- **`minesweeper`** - Minesweeper game using `QTableView` and `QStandardItemModel`
- **`Chess`** - Chess game implementation in Qt
- **`Calculator`** - Desktop calculator app
- **`BMI`** - BMI calculation tool
- **`passGen`** - Password generator
- **`table`** & **`tabulka_qt`** - Table models and view handling
- **`9x9table`** - 9x9 grid table practice
- **`listView`** - Qt `QListView` examples
- **`tictactoe5x6`** & **`tictactoe_cpp`** - Tic Tac Toe games
- **`hruba-cistaMzda`** - Gross to net wage calculation
- **`first`**, **`ddsada`**, **`spejle`**, **`pisemka`**, **`test7-10`**, **`test14-10`**, **`untitled*`** - School tests, practice, and prototypes
- **`tableView-procvicovani`** - Documentation and practice exercises for table views
